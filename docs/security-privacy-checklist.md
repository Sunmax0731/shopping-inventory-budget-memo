# Security / Privacy Checklist

        ## 方針

        購入履歴は端末内保存とし、決済情報や位置情報を扱わない

        ## チェック

        - [x] 外部送信をMVP外にした。
        - [x] サンプルに実個人情報を含めない。
        - [x] 手動テストで確認すべき権限を列挙。
        - [x] release asset に手動テスト手順を添付。

        ## Android / Host 権限

        - CAMERA とバーコード読み取りはMVP外
- ネットワーク権限なし

        ## Adobe 公式参照

        - 対象ドメイン docs と created_idea metadata を優先。
